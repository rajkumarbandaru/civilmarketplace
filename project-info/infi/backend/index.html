Paths

3Recharge

Bundle top-up → PaymentFacade validators, routing and dispatch → webhook confirm or wallet debit → BUNDLE_ACTIVATION → carrier applies the plan.

Paths
Card → Verizon subscriber18 steps
Wallet balance → T-Mobile subscriber14 steps
Key tables
gateway_transactionprepaid_subscription_recordsvoucher_redeem_logrecharge_auto_renewalpwg_recharge_flow_logs
